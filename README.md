# meganamasa

Personal portfolio site for Megan Amasa — Duke CS + Entrepreneurship, Class of 2027.

Covers background (Fora Travel, Campus Enterprises), selected work and demos, and research interests in AI + consumer behavior and holistic health.

## Stack
- Single static `index.html` (hand-written HTML/CSS/JS, no build step)
- Fonts: Cormorant Garamond, Syne, JetBrains Mono
- Research papers served as PDFs from the repo root

## Run locally
```bash
open index.html          # or: npx serve .
```

## Deploy
Hosted on Vercel. Pushes to `main` deploy to production.
